# 클릭형 논문 워드클라우드 수정본

첨부받은 Streamlit 워드클라우드 코드를 바탕으로, 키프레이즈 클릭 → 관련 논문 목록 기능을 추가한 버전입니다.

## 기존 프로젝트에 적용

1. 기존 파일을 백업합니다.
2. 이 폴더의 `app.py`, `keyphrase_cloud.py`로 기존 두 파일을 교체합니다.
3. 새 파일 `paper_explorer.py`를 **두 파일과 같은 폴더**에 추가합니다.
4. 기존 `config/` 폴더와 `requirements.txt`는 그대로 사용할 수 있습니다. 압축파일의 config는 이번에 첨부받은 설정 원본입니다. 이후 직접 변경한 설정이 있다면 기존 것을 유지하세요.
5. Streamlit을 재시작하고 **분석 시작**을 다시 누릅니다. 기존 PNG·Excel만으로는 논문 연결을 복원할 수 없습니다. 기존 품사 분석 캐시는 재사용합니다.

GitHub에 직접 올릴 때도 위 세 Python 파일을 같은 폴더에 넣고 기존 Streamlit 시작 파일을 `app.py`로 지정하면 됩니다. 이 수정 작업에서 GitHub 업로드나 배포는 하지 않았습니다.

## 새로 설치하는 경우

압축을 풀고 이 README가 있는 폴더에서 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

필수 입력 열: `Title`, `Abstract`, `Author Keywords` (기존과 같음).
있으면 추가 표시: `Authors` 또는 `Author full names`, `Year`, `Source title`, `DOI`, `Link`, `Cited by` 또는 `Times Cited`.

## 화면 사용법

- 왼쪽 워드클라우드의 글자를 누르면 오른쪽에 관련 논문이 나옵니다.
- 작은 글자는 아래 키프레이즈 선택 목록으로도 선택할 수 있습니다.
- ‘전체 (단어 + 구문)’와 ‘구문만 (2단어 이상)’을 선택할 수 있습니다.
- 검색, 발견 위치(제목·초록·저자키워드), 등장횟수순·피인용순·최신순 정렬을 제공합니다.
- 논문별 제목, 저널·연도, 저자, 발견 위치와 등장 횟수, 피인용, 초록을 확인할 수 있습니다. 링크/DOI가 있을 때 원문 링크가 표시됩니다.
- 저자는 세미콜론으로 구분된 경우 최대 20명까지 표시합니다.
- 표시되는 논문은 선택한 분석 영역에서 **실제로 집계된 논문**입니다. 원문 문자열을 다시 검색하는 방식이 아닙니다.
- 표시명에 서로 다른 정규화 키가 합쳐진 경우 연결 논문도 합쳐 중복 논문은 한 번만 표시합니다.
- 화면은 검색·정렬 결과 상위 100편까지 표시하고 CSV는 현재 조건에 맞는 전체 논문을 내보냅니다.

## 결과 파일

기존 Excel과 전체/구문 PNG를 유지하고, `결과이름_논문탐색.html` 파일 하나를 추가합니다.
HTML은 이미지·논문 정보를 자체 포함하므로 Chrome/Edge에서 단독으로 열 수 있습니다. 별도 JSON·클릭 판정 이미지 파일은 만들지 않습니다. HTML 안의 다운로드는 PNG와 현재 목록 CSV입니다.
HTML에는 워드클라우드에 실제 배치된 키프레이즈와 연결된 논문 정보(초록 포함)가 들어갑니다. 공유 시 해당 데이터도 함께 전달됩니다.

## 변경 범위

- 기존 구문 자동 후보 생성, 품사 처리, 동의어·불용어, 빈도 계산, count/papers 순위 기준을 유지했습니다.
- `count_phrases()`: 집계와 동시에 정규화 키별 논문 ID와 영역별 횟수를 기록합니다.
- `make_wordcloud()`: 원본과 같은 배치를 유지하며 글자별 픽셀 ID와 위치를 메모리에 기록합니다.
- `paper_explorer.py`: 자체 포함 HTML을 생성합니다. 원문 텍스트는 HTML로 실행하지 않고 일반 텍스트로 표시합니다.
- `app.py`: 기존 결과 이미지 위치에 클릭 가능한 HTML을 삽입합니다.
- 클릭 판정은 실제 글자 픽셀을 우선하며 화면상 5px 이내 가장 가까운 글자를 선택합니다. 큰 글자의 사각형이 작은 글자를 가리지 않습니다.
- 목록의 ‘등장횟수순’은 선택한 키프레이즈의 논문별 영역 합계입니다. 워드클라우드 전체 순위 설정(count/papers)을 바꾸는 기능이 아닙니다. 피인용은 목록 정렬에만 쓰며 새 순위 가중치를 추가하지 않았습니다.

## 검증 범위

시험용 논문 8편으로 실제 spaCy 분석부터 Excel/PNG/HTML 저장까지 실행했습니다. 원본과 수정본의 키프레이즈 표·제외표가 같고 PNG 파일도 바이트 단위로 같았습니다. HTML에 연결된 논문 수와 영역별 등장 횟수가 표의 집계와 일치하는지 검사했습니다.

추가로 약어·동의어 연결, 복합어 우선 집계, 분석 영역 필터와 JavaScript 클릭·검색·정렬·다운로드 처리 로직을 검사했습니다. Streamlit AppTest에서 파일 경로 입력 → 분석 시작 → HTML 결과 표시까지 오류 없이 완료했습니다. 실제 브라우저 렌더링 및 GitHub/Streamlit Cloud 배포 환경 테스트는 수행하지 못했습니다.
